Algorithms & complexity

V = users, E = connections. Adjacency list gives O(V + E) space.

FeatureAlgorithmTimeSpace
Explore nearest firstBFS (queue)O(V+E)O(V)
Explore deep firstDFS (stack / recursive)O(V+E)O(V)
Mutual connectionsSet intersectionO(min(da,db))O(min(da,db))
Shortest pathBFS + parentsO(V+E)O(V)
Shortest path (fast)Bidirectional BFS~O(b^(d/2))O(V)
CommunitiesBFS from each unvisited userO(V+E)O(V)

Use it as a library

Python 3.9+, standard library only.

from socialnet import SocialGraph, shortest_path, mutual_connections, recommend_friends

g = SocialGraph.from_edges([("A","B"),("B","C"),("A","D"),("D","C"),("C","E")])
shortest_path(g, "A", "E")       # ['A', 'B', 'C', 'E']
mutual_connections(g, "A", "C")  # {'B', 'D'}
recommend_friends(g, "A")        # [('C', 2)]
